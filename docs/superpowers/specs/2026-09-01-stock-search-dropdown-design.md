# 个股搜索下拉选择设计

## 目标

将个股追踪的股票输入框改为“搜索 + 下拉选择 + 确认添加”交互，Web 端和微信小程序端保持一致。

## 交互规则

1. 用户输入中文名称或股票代码后，前端防抖请求搜索接口并展示候选项。
2. 点击候选项只记录选中的股票，不立即写入追踪列表。
3. 选中后输入框展示股票名称和代码，点击“添加股票”才调用添加接口。
4. 用户再次编辑输入内容时清除已选股票；未选中候选项时添加按钮不可用。
5. 已追踪股票候选项保持可见但不可重复添加，并给出已追踪状态。

## 实现边界

- 复用现有 `GET /api/stocks/search` 与添加股票接口，不改后端领域模型。
- Web 使用 React 状态管理选中项；小程序使用页面 data 管理选中项。
- 测试覆盖搜索结果选中、未选中禁止提交、选中后提交代码三个核心行为。

## 验收标准

- 输入“贵州”可显示候选股票。
- 点击候选项后不会立即添加。
- 未选中候选项点击添加不会发起添加请求。
- 选中“贵州茅台”后点击添加，提交 `600519.SH`。
- Web 测试、构建通过；小程序页面代码静态检查通过。
